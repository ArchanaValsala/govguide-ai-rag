# GovGuide AI API

## Overview

GovGuide AI exposes an HTTP webhook that accepts a user question and returns a grounded answer based on official source material stored in Supabase.

The API runs locally through n8n.

## Endpoint

```text
POST /webhook/govguide-question
```

Local development URL:

```text
http://localhost:5678/webhook/govguide-question
```

## Request Headers

```text
Content-Type: application/json
```

## Request Body

The request body must contain a `question` field.

```json
{
  "question": "Why do I have to repay part of my allowance?"
}
```

## Request Rules

The `question` field:

- must be present
- must be a string
- must not be empty
- must contain at least 5 characters
- must not exceed 1000 characters

## Successful Response

A successful request returns HTTP status `200`.

Example:

```json
{
  "question": "Why do I have to repay part of my allowance?",
  "topic": "repayment",
  "answer": "You may have to repay part of your allowance when the amount you received was higher than the amount you were entitled to based on your final income or personal situation.",
  "sources": [
    {
      "source_id": "TOE-003",
      "source_title": "Waarom moet ik toeslag terugbetalen?",
      "source_url": "https://www.belastingdienst.nl/wps/wcm/connect/nl/toeslag-terugbetalen/content/waarom-moet-ik-toeslag-terugbetalen"
    }
  ]
}
```

## Response Fields

### `question`

The original normalized user question.

### `topic`

The topic selected by the rule-based classifier.

### `answer`

The answer generated by the local Ollama model using only the retrieved source context.

### `sources`

A deduplicated list of official sources used to generate the answer.

Each source may contain:

```json
{
  "source_id": "TOE-003",
  "source_title": "Waarom moet ik toeslag terugbetalen?",
  "source_url": "https://www.belastingdienst.nl/wps/wcm/connect/nl/toeslag-terugbetalen/content/waarom-moet-ik-toeslag-terugbetalen"
}
```

## Supported Topics

The current version supports these topics:

```text
income_change
definitive_calculation
repayment
payment_arrangement
objection
review_request
```

## Example curl Request

```bash
curl -i -X POST http://localhost:5678/webhook/govguide-question \
  -H "Content-Type: application/json" \
  -d '{
    "question": "My income has changed. Do I need to report it?"
  }'
```

## Example Successful curl Response

```text
HTTP/1.1 200 OK
Content-Type: application/json
```

```json
{
  "question": "My income has changed. Do I need to report it?",
  "topic": "income_change",
  "answer": "Yes. If you receive an allowance, you should report an income change through Mijn toeslagen or the Toeslagen app. This helps prevent receiving too much or too little allowance.",
  "sources": [
    {
      "source_id": "TOE-001",
      "source_title": "Mijn inkomen verandert - moet ik dat doorgeven?",
      "source_url": "https://www.belastingdienst.nl/wps/wcm/connect/nl/werk-en-inkomen/content/mijn-inkomen-verandert-moet-ik-dat-doorgeven"
    }
  ]
}
```

## Error Status Codes

The API can return the following controlled error responses:

```text
400 → Invalid question
404 → No relevant vector-search results
422 → Unsupported topic
503 → Answer generation failure
```

See `error-handling.md` for full details.
